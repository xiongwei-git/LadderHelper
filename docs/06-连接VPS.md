# 连接 VPS

这一章要做的事，是从你的电脑登录到刚买的 VPS。登录成功后，后面才能在服务器里安装 3x-ui 代理服务。

如果你完全没用过终端，也不用紧张。这里用到的命令很少，你只需要照着输入即可。

> ✅ 先看结论：连接 VPS 需要四个信息：公网 IP、SSH 端口、登录用户名、登录密码。

## 🧾 你需要准备的信息

在开始连接之前，先从 VPS 控制台里找到并记录这些信息：

- VPS 公网 IP。
- SSH 端口。
- 登录用户名。
- 登录密码，或 SSH 密钥。

常见 Linux VPS 的默认用户名是：

```text
root
```

但不同服务商可能不一样，最终以控制台显示为准。如果看不到密码，可以回到上一章提到的“重置密码”入口重新设置。

## 🍎 macOS 连接方式

macOS 可以直接使用系统自带的“终端”。

打开方式：

```text
启动台 -> 其他 -> 终端
```

或者使用 Spotlight 搜索“终端”。

如果你的 SSH 端口是默认的 `22`，输入：

```bash
ssh root@你的服务器IP
```

比如：

```bash
ssh root@137.220.151.102
```

如果服务商给了特殊 SSH 端口，例如 `22222`，则输入：

```bash
ssh root@你的服务器IP -p 22222
```

比如：

```bash
ssh root@137.220.151.102 -p 22222
```

## 🪟 Windows 连接方式

Windows 可以使用下面这些工具：

- Windows Terminal。
- PowerShell。
- FinalShell。
- Xshell。

如果使用 Windows Terminal 或 PowerShell，命令和 macOS 类似：

```bash
ssh root@你的服务器IP
```

如果使用 FinalShell、Xshell 这类图形化工具，只需要把下面几项填进去：

| 字段 | 填什么 |
| --- | --- |
| 主机 / Host | VPS 公网 IP |
| 端口 / Port | SSH 端口，默认通常是 `22` |
| 用户名 / Username | 通常是 `root` |
| 密码 / Password | VPS 登录密码 |

## 🔐 第一次连接时会看到什么

第一次连接一台新服务器时，终端可能会提示：

```text
Are you sure you want to continue connecting?
```

这表示你的电脑第一次见到这台服务器，询问是否继续连接。

输入：

```text
yes
```

然后按回车。

接下来会要求输入密码。注意：终端里输入密码时，屏幕上通常不会显示任何字符，也不会显示星号。这是正常现象。

你只需要正常输入密码，然后按回车即可。

## ✅ 怎么判断已经连接成功

如果连接成功，你会看到类似这样的提示符：

```text
root@server:~#
```

或者：

```text
root@hostname:~$
```

只要前面出现了 `root@` 或类似的服务器用户名，就说明你已经进入 VPS 了。

这时候你输入的命令，就不是在你的电脑上执行，而是在远程服务器上执行。

## 🧪 登录后可以先检查一下

登录成功后，可以输入：

```bash
whoami
```

如果返回：

```text
root
```

说明当前登录用户是 `root`。

也可以输入：

```bash
pwd
```

如果返回类似：

```text
/root
```

说明你已经在服务器的 root 用户目录下。

## 🧯 常见连接失败原因

如果连接失败，先按下面顺序检查：

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| 连接超时 | IP 错误、服务器没开机、防火墙或安全组没放行 | 检查 VPS 控制台和安全组 |
| 密码错误 | 密码输错，或重置后未生效 | 重新复制密码，必要时重置密码 |
| 用户名错误 | 服务商默认用户名不是 `root` | 查看控制台里的用户名 |
| 端口错误 | SSH 端口不是 `22` | 在命令里加 `-p 端口号` |
| Permission denied | 密码或密钥不匹配 | 检查认证方式 |

> ⚠️ 提醒：如果你多次输入密码失败，不要一直乱试。先回到 VPS 控制台确认用户名、端口和密码是否正确。

## ✅ 这一章你需要得到什么

完成这一章后，你至少要做到：

- 能从电脑连接到 VPS。
- 知道自己的 SSH 用户名和端口。
- 知道密码输入不显示是正常现象。
- 能看到类似 `root@server:~#` 的服务器命令行。

连接成功后，下一章先确认服务器端口开放方式，然后再安装 3x-ui。
