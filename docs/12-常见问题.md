# 常见问题

这一章集中回答搭建过程中最容易遇到的问题。遇到问题时，不要先怀疑所有步骤都错了，按现象逐项排查。

## 💰 自建一定比买服务便宜吗

不一定。一个人使用时，自建未必便宜。几个人分摊时，长期成本可能更低。

## 🔐 自建一定更安全吗

不一定。安全取决于服务商、配置、密码强度、面板暴露情况和个人使用习惯。

## 🧭 为什么我换了代理，账号还是有问题

因为很多平台不只看 IP。账号行为、浏览器环境、系统时区、支付方式、邮箱访问环境都可能影响风控。

## 🖥️ 为什么我买了 VPS 但连不上

常见原因：

- 安全组没放行端口。
- 防火墙没放行端口。
- VPS 系统没启动。
- 3x-ui 服务没启动。
- 客户端配置错了。
- 服务商限制了用途。

## 🌐 为什么域名解析了还是打不开

常见原因：

- 解析还没生效。
- A 记录填错 IP。
- 访问的是根域名，但你配置的是子域名。
- 端口不通。
- 服务没启动。

## ⚠️ 服务商禁止代理怎么办

不要继续使用这台服务器搭建代理。违反条款可能导致停机、封号或无法退款。应选择条款允许、用途匹配的服务。
