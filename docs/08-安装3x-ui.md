# 安装 3x-ui

3x-ui 是一个开源的 Xray-core 管理面板。安装完成后，你可以通过网页后台创建节点、管理用户、查看流量，并复制客户端配置。

这一章会用真实安装过程来讲解，但所有敏感信息都已经脱敏。你实际安装时看到的域名、用户名、密码、面板路径、API Token 都会和示例不同。

> ✅ 先看结论：安装脚本会自动下载 3x-ui，询问数据库、面板端口、证书方式，最后生成面板登录地址、用户名和密码。安装完成后一定要保存这些信息。

## 🧾 安装前检查

开始安装前，先确认这些事情已经完成：

- VPS 已经可以通过 SSH 登录。
- 域名已经解析到 VPS 公网 IP。
- 服务商控制台已经开放需要的端口。
- `80`、`443`、SSH 端口和预留端口范围已经处理好。
- 你准备好一个记录工具，用来保存面板地址、账号、密码和路径。

如果你准备用域名申请证书，`80` 端口必须能从外部访问，否则 Let's Encrypt 证书验证可能失败。

## 🧰 安装必要工具

3x-ui 官方安装脚本需要用到 `curl`。

如果你使用 Ubuntu / Debian，可以先执行：

```bash
apt update
apt install curl -y
```

如果你使用 CentOS / Rocky / AlmaLinux，可以先执行：

```bash
yum install curl -y
```

如果系统提示 `curl` 已经安装，可以继续下一步。

## 🚀 一行安装 3x-ui

3x-ui 官方 Wiki 推荐的安装命令是：

```bash
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```

复制命令后，在 VPS 的 SSH 终端里执行。

执行后，你会看到类似这样的输出：

| English output | 中文解释 |
| --- | --- |
| `The OS release is: centos` | 脚本识别到当前服务器系统是 CentOS |
| `Arch: amd64` | 服务器 CPU 架构是 amd64 |
| `Got x-ui latest version: v3.4.2` | 脚本获取到当前 3x-ui 最新版本 |
| `beginning the installation...` | 开始安装 |

版本号可能会变化，以你实际看到的为准。

## 🗄️ 选择数据库

安装过程中会出现数据库选择：

```text
Database Selection
1) SQLite     (default — recommended for < 500 clients)
2) PostgreSQL (recommended for high client counts / many nodes)
Choose [1]:
```

中英文对照：

| English prompt | 中文解释 | 新手建议 |
| --- | --- | --- |
| `SQLite` | 本地轻量数据库 | 个人使用选这个 |
| `PostgreSQL` | 独立数据库服务 | 大量用户或复杂场景再考虑 |
| `Choose [1]:` | 请选择数据库 | 输入 `1` |

新手直接输入：

```text
1
```

个人使用、家人朋友少量使用，SQLite 足够。

## 🔌 设置面板端口

接着会询问是否自定义面板端口：

```text
Would you like to customize the Panel Port settings?
(If not, a random port will be applied) [y/n]:
```

中文意思是：是否要自己设置面板端口？如果不设置，脚本会随机生成一个端口。

这里建议输入：

```text
y
```

然后脚本会继续问：

```text
Please set up the panel port:
```

你可以输入一个自己准备好的端口，例如：

```text
30000
```

如果你输入的是 `80`，面板地址会使用 `80` 端口。但更建议把面板端口放在前面预留的 `30000-40000` 范围内，方便管理，也避免和证书申请用到的 `80` 端口混在一起。

> ⚠️ 注意：你设置的面板端口，必须已经在服务商控制台防火墙或安全组里放行。

## 🔐 选择 SSL 证书方式

脚本会提示 SSL 证书配置：

```text
SSL Certificate Setup (RECOMMENDED)
SSL is strongly recommended.
Choose SSL certificate setup method:
1. Let's Encrypt for Domain
2. Let's Encrypt for IP Address
3. Custom SSL Certificate
4. Skip SSL
```

中英文对照：

| English option | 中文解释 | 适合情况 |
| --- | --- | --- |
| `Let's Encrypt for Domain` | 用域名申请免费证书 | 推荐，有自己的域名时选这个 |
| `Let's Encrypt for IP Address` | 用 IP 申请证书 | 没有域名时临时使用 |
| `Custom SSL Certificate` | 使用已有证书文件 | 有证书经验的人使用 |
| `Skip SSL` | 跳过证书，使用普通 HTTP | 不建议新手选择 |

如果你已经完成了前面的域名解析，建议选择：

```text
1
```

脚本还会提醒：

```text
Options 1 & 2 require port 80 open.
```

中文意思是：选项 1 和 2 都需要开放 `80` 端口。

## 🌐 输入你的域名

选择域名证书后，脚本会要求输入域名：

```text
Please enter your domain name:
```

这里输入你已经解析到这台 VPS 的完整域名，例如：

```text
your-node.example.com
```

脚本会检查域名是否可用：

| English output | 中文解释 |
| --- | --- |
| `Your domain is: your-node.example.com, checking it...` | 正在检查域名 |
| `Your domain is ready for issuing certificates now...` | 域名已经可以申请证书 |
| `Please choose which port to use (default is 80):` | 选择用于证书验证的端口，默认是 80 |

这里通常直接输入：

```text
80
```

如果域名没有正确解析到 VPS，或者 `80` 端口没有开放，证书申请可能会失败。

## 📜 证书申请过程怎么看

申请证书时，你会看到很多英文输出。新手不用逐行看懂，只要关注几个关键结果。

| English output | 中文解释 |
| --- | --- |
| `Using Let's Encrypt for domain certificate...` | 正在使用 Let's Encrypt 为域名申请证书 |
| `acme.sh could not be found. Installing now...` | 没找到 acme.sh，脚本会自动安装 |
| `Verifying: your-node.example.com` | 正在验证你的域名 |
| `Success` | 验证成功 |
| `Cert success.` | 证书申请成功 |
| `Installing certificate succeeded` | 证书安装成功 |

如果输出里出现整段：

```text
-----BEGIN CERTIFICATE-----
...
-----END CERTIFICATE-----
```

这是证书内容，不需要复制，也不要放到公开文档里。

## 🔄 证书续期后的重启命令

证书安装后，脚本可能会问：

```text
Would you like to modify --reloadcmd for ACME? (y/n):
```

中文意思是：证书签发或续期后，要不要修改自动重载命令。

如果你看到预设选项：

```text
1. Preset: systemctl reload nginx ; systemctl restart x-ui
2. Input your own command
0. Keep default reloadcmd
```

新手可以优先选择默认或预设方案。如果你的服务器没有安装 nginx，看到类似下面的提示也不一定代表 3x-ui 安装失败：

```text
Failed to reload nginx.service: Unit nginx.service not found.
```

这只是说明服务器里没有 nginx 这个服务。重点看后面是否出现 3x-ui 安装完成和服务运行成功。

## ✅ 安装完成时要保存什么

安装成功后，会出现类似这样的结果：

```text
Panel Installation Complete!
Username:    <PANEL_USERNAME>
Password:    <PANEL_PASSWORD>
Port:        <PANEL_PORT>
WebBasePath: <PANEL_PATH>
Database:    SQLite (/etc/x-ui/x-ui.db)
Access URL:  https://your-node.example.com:<PANEL_PORT>/<PANEL_PATH>/
API Token:   <API_TOKEN>
IMPORTANT: Save these credentials securely!
```

中英文对照：

| English field | 中文解释 | 是否需要保存 |
| --- | --- | --- |
| `Username` | 面板用户名 | 必须保存 |
| `Password` | 面板密码 | 必须保存 |
| `Port` | 面板端口 | 必须保存 |
| `WebBasePath` | 面板访问路径 | 必须保存 |
| `Access URL` | 面板完整登录地址 | 必须保存 |
| `API Token` | API 访问令牌 | 保存但不要公开 |

这些内容非常重要。尤其是 `WebBasePath`，它是登录地址的一部分，不是可有可无的备注。

> ⚠️ 不要把真实用户名、密码、面板路径、API Token 发给别人，也不要截图公开。

## 🧯 关于 Fail2ban 提示

安装后你可能会看到：

```text
Fail2ban is not installed. Installing now...!
Error: Unable to find a match: fail2ban
Fail2ban installation failed.
Fail2ban setup did not finish; IP Limit stays disabled...
```

中文意思是：脚本尝试安装 Fail2ban，但当前系统源里没有找到对应软件包，所以 IP 限制功能暂时没有启用。

这通常不影响 3x-ui 基础安装，也不影响你进入面板创建节点。后面如果需要 IP 限制功能，可以再单独处理。

## ⚙️ 第二阶段：安装后基础配置

安装完成后，建议再做一次基础配置。目的不是复杂优化，而是确认面板可用、端口正确、服务能开机自启。

在服务器里输入：

```bash
x-ui
```

你会看到 3x-ui 管理菜单，类似下面这些选项：

| 菜单编号 | English menu | 中文解释 |
| --- | --- | --- |
| `7` | `Reset Username & Password` | 重置面板用户名和密码 |
| `10` | `Change Port` | 修改面板端口 |
| `11` | `View Current Settings` | 查看当前面板设置 |
| `14` | `Restart` | 重启 x-ui 和 xray |
| `18` | `Enable Autostart` | 设置开机自启 |
| `26` | `Enable BBR` | 启用 BBR 网络优化 |
| `27` | `Update Geo Files` | 更新 Geo 规则文件 |

菜单底部如果看到：

```text
Panel state: Running
Start automatically: Yes
xray state: Running
```

含义是：

| English status | 中文解释 |
| --- | --- |
| `Panel state: Running` | 面板正在运行 |
| `Start automatically: Yes` | 已经设置开机自启 |
| `xray state: Running` | Xray 核心正在运行 |

## 👤 重置面板用户名和密码

如果你不想使用安装脚本自动生成的随机用户名和密码，可以在菜单里选择：

```text
7. Reset Username & Password
```

脚本会询问：

```text
Are you sure to reset the username and password of the panel? [Default n]:
```

输入：

```text
y
```

然后按提示设置新的用户名和密码：

```text
Please set the login username [default is a random username]: <NEW_USERNAME>
Please set the login password [default is a random password]: <NEW_PASSWORD>
```

中英文对照：

| English prompt | 中文解释 |
| --- | --- |
| `Please set the login username` | 设置新的面板登录用户名 |
| `Please set the login password` | 设置新的面板登录密码 |
| `Do you want to disable currently configured two-factor authentication?` | 是否关闭当前配置的两步验证 |
| `Panel login username has been reset to...` | 面板用户名已重置 |
| `Panel login password has been reset to...` | 面板密码已重置 |

> ⚠️ 教程里不要写真实用户名和密码。建议把真实密码保存在密码管理器里。

重置完成后，脚本会询问是否重启面板：

```text
Restart the panel, Attention: Restarting the panel will also restart xray [Default y]:
```

这里建议输入：

```text
y
```

看到下面提示，说明重启成功：

```text
[INF] x-ui and xray Restarted successfully
```

## 🔌 修改面板端口

如果安装时临时用了不合适的端口，可以在菜单里选择：

```text
10. Change Port
```

脚本会要求输入新端口：

```text
Enter port number[1-65535]:
```

例如输入：

```text
30000
```

成功后会看到：

```text
Port set successfully: 30000
The port is set, Please restart the panel now...
```

这里同样建议重启面板：

```text
y
```

> ⚠️ 修改端口前，确认这个端口已经在服务商控制台防火墙或安全组里放行。否则改完端口后，浏览器可能打不开面板。

## 🚀 设置开机自启

为了避免服务器重启后 3x-ui 不自动启动，可以在菜单里选择：

```text
18. Enable Autostart
```

成功后会看到：

```text
[INF] x-ui Set to boot automatically on startup successfully
```

中文意思是：x-ui 已经设置为开机自动启动。

## 🛣️ 启用 BBR

BBR 是一种 TCP 拥塞控制算法，常用于改善网络传输体验。

在菜单里选择：

```text
26. Enable BBR
```

然后选择：

```text
1. Enable BBR
```

成功后可能会看到：

```text
net.core.default_qdisc = fq
net.ipv4.tcp_congestion_control = bbr
BBR has been enabled successfully.
```

中文意思是：BBR 已经启用成功。

> ✅ 新手可以开启 BBR。它通常不会影响后续操作，但也不是“速度一定变快”的保证。

## 🗺️ 更新 Geo 文件

Geo 文件用于规则识别，例如地区、站点分类等。

在菜单里选择：

```text
27. Update Geo Files
```

如果出现选项：

```text
1. Loyalsoldier
2. chocolate4u
3. runetfreedom
4. All
0. Back to Main Menu
```

新手可以选择：

```text
4
```

成功后会看到类似：

```text
geoip.dat: updated
geosite.dat: updated
geo files have been updated successfully!
[INF] x-ui and xray Restarted successfully
```

中文意思是：Geo 规则文件已经更新，x-ui 和 xray 已经重启。

## 🔍 查看当前设置

最后建议查看一次当前面板设置。

在菜单里选择：

```text
11. View Current Settings
```

你会看到类似：

```text
Panel is secure with SSL
hasDefaultCredential: false
port: <PANEL_PORT>
webBasePath: /<PANEL_PATH>/
Database: SQLite (/etc/x-ui/x-ui.db)
Access URL: https://your-node.example.com:<PANEL_PORT>/<PANEL_PATH>/
```

中英文对照：

| English field | 中文解释 |
| --- | --- |
| `Panel is secure with SSL` | 面板已经启用 SSL |
| `hasDefaultCredential: false` | 已经不是默认账号密码 |
| `port` | 当前面板端口 |
| `webBasePath` | 当前面板访问路径 |
| `Access URL` | 当前完整访问地址 |

这一步非常重要。请把 `Access URL`、端口、路径、用户名和密码都记录下来。

## 🗂️ 安装信息记录表

安装完成后，把这些信息记录下来：

| 信息 | 内容 |
| --- | --- |
| 面板域名 | 待填写 |
| 面板端口 | 待填写 |
| 面板路径 | 待填写 |
| 面板用户名 | 待填写 |
| 面板密码 | 待填写 |
| 完整登录地址 | 待填写 |
| API Token | 待填写，注意保密 |

## ✅ 这一章你需要得到什么

完成这一章后，你至少要得到：

- 3x-ui 已经安装成功。
- 面板可以通过 HTTPS 地址访问。
- 已经保存面板用户名、密码、端口、路径和完整访问地址。
- 知道可以用 `x-ui` 命令进入管理菜单。
