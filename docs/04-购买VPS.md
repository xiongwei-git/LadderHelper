# 购买 VPS

VPS 可以理解成一台租来的远程电脑。后面我们会把 3x-ui 和代理服务安装在这台服务器上。

这一章的目标不是让你买最贵的服务器，而是帮你买一台“够用、能跑通流程、损失可控”的 VPS。

> ✅ 先看结论：第一次搭建，先买一台 VPS 就够了。不要一开始就买三台，也不要一开始就追求复杂线路。

## 🧭 选择 VPS 看什么

买 VPS 时，不要只看价格。下面这些指标都会影响后续体验。

| 指标 | 为什么重要 |
| --- | --- |
| 地区 | 决定出口 IP 所在国家或地区 |
| 带宽 | 影响访问速度和多人使用体验 |
| 月流量 | 影响每月可用量和账单 |
| 稳定性 | 影响是否经常断线、关机或重启 |
| 价格 | 影响长期使用成本 |
| 网络优化 | 影响国内连接到服务器的速度 |
| 服务条款 | 决定服务商是否允许你的使用方式 |

对新手来说，最重要的是三点：地区合适、线路能用、价格能接受。

## ⚠️ 先说明：这是经验分享，不是服务质量保证

下面提到的服务商，是基于我的个人使用经验整理的选择范围，不代表对服务质量做保证，也不代表这些服务商一定长期稳定。

购买前请注意：

- 价格、套餐、带宽、流量规则都会变化，以官网实时页面为准。
- 服务商可能调整规则、限制用途，甚至出现停机或跑路风险。
- 购买前要自己判断，不要只因为教程里提到就直接下单。
- 如果通过我的推荐链接购买，我可能会获得少量推荐费用，通常是几元到十几元，用来抵扣我自己的服务器费用。

> ⚠️ 特别提醒：如果服务商条款明确禁止 VPN、代理或类似用途，你需要自行评估风险。技术上能安装，不代表服务条款一定允许。

## 🛣️ 为什么强调线路优化

VPS 在海外，不代表从国内访问它就一定快。

对新手来说，建议优先选择标注了这些关键词的套餐：

- 大陆优化
- 三网优化
- CN2
- CMI
- 优化线路

这些词不保证一定快，但通常比完全普通线路更适合新手直接使用。

如果你后面学会中转、负载均衡、多节点切换，再去折腾非优化网络会更合适。

## 🧑‍💻 系统镜像怎么选

购买 VPS 时，需要选择服务器系统。

如果你跟着本教程走，建议优先选择常见 Linux 系统，例如：

- CentOS 8以上版本系统
- Ubuntu LTS
- Debian

我个人习惯 CentOS 所以经常选择CentOS，但新手不要选太冷门的系统。系统越常见，后面遇到问题越容易查资料。

> ⚠️ 注意：有些老版本系统已经停止维护。购买时尽量选择服务商当前推荐的稳定版本。

## ✅ 新手选择建议

如果只是第一次学习，建议先买一台 VPS，不要一开始就买三台。

更稳妥的路线是：

1. 先买一台便宜、损失可接受的 VPS。
2. 跑通完整流程。
3. 确认自己会安装、连接、排错。
4. 再考虑主节点、备用节点、多地区节点。

如果你是重度用户，或者家人也要一起使用，后续可以再考虑多节点方案。

## 🛒 购买 VPS 的步骤

不同服务商页面不一样，但购买流程大致相同。

1. 选择服务器地区。
2. 选择系统镜像。
3. 选择 CPU、内存、硬盘、带宽。
4. 确认是否有大陆优化或三网优化线路。
5. 确认流量规则和续费价格。
6. 设置登录密码或 SSH 密钥。
7. 完成付款。
8. 进入服务器控制台。
9. 复制服务器公网 IP。

拿到公网 IP 后，先保存到前面准备的信息记录表里。下一章会把域名解析到这个 IP。

## 🔑 如何获得 VPS 登录用户名和密码

购买 VPS 后，进入服务商的服务器控制台，一般都能看到服务器的登录信息。

你需要重点找到这几项：

- 公网 IP。
- 登录用户名。
- 登录密码，或重置密码入口。
- SSH 端口。

大多数 Linux VPS 的默认用户名是：

```text
root
```

有些服务商也可能使用 `ubuntu`、`admin` 等用户名，具体以控制台显示为准。

如果控制台里看不到密码，不代表服务器不能登录。通常可以在控制台里找到“重置密码”“修改密码”或“重设 root 密码”之类的按钮。

重置密码后，建议把新密码记录到前面的信息记录表里。

> ⚠️ 注意：重置密码后，有些服务商需要重启服务器才能生效。如果你重置后仍然登录失败，可以回到控制台检查是否需要重启。

## ✅ 这一章你需要得到什么

完成这一章后，你至少要得到：

- 一台已经购买成功的 VPS。
- VPS 的公网 IP。
- VPS 的登录用户名和密码，或 SSH 密钥。
- 知道服务器系统是什么。
- 知道这个套餐的带宽、流量和续费价格。

如果你还不确定买哪家，先不要急着付款。优先选择便宜、可承受、能跑通教程的方案。
