# 客户端配置与测试

节点创建完成后，需要导入到电脑或手机的代理客户端里。

> ✅ 先看结论：优先使用订阅链接或二维码导入，不建议新手手动填写一大堆参数。

## 🧰 客户端选择

这部分可以按你自己的使用习惯填写。

| 平台 | 推荐客户端 | 备注 |
| --- | --- | --- |
| macOS | 待填写 | 例如是否支持订阅、规则、测速 |
| Windows | 待填写 | 适合新手优先 |
| iPhone | 待填写 | 注意 App Store 区域 |
| Android | 待填写 | 注意安装来源 |

## 📥 导入方式

常见导入方式：

- 复制订阅链接。
- 扫描二维码。
- 手动填写节点信息。

新手优先用订阅链接或二维码，不建议手动填大量参数。

## 🧭 代理模式

| 模式 | 含义 | 适合谁 |
| --- | --- | --- |
| 全局代理 | 所有流量都走代理 | 临时测试 |
| 规则代理 | 指定网站走代理，其他直连 | 长期使用 |
| 直连 | 不使用代理 | 排查问题 |

长期使用建议选择“规则代理”，不要一直开全局。

## 🧪 测试是否成功

测试顺序：

1. 客户端显示已连接。
2. 打开 IP 查询网站，确认出口地区是 VPS 所在地区。
3. 打开目标服务，确认可以访问。
4. 关闭代理再访问一次，确认差异。

## 🧯 常见测试结果

| 现象 | 可能原因 | 处理方向 |
| --- | --- | --- |
| 客户端连不上 | 节点配置错、端口没开、服务没启动 | 回到 3x-ui 检查节点 |
| IP 没变化 | 代理规则没生效 | 检查客户端模式 |
| 能连但很慢 | 线路质量一般、带宽不足 | 换地区或服务商 |
| 一会儿能用一会儿不能用 | VPS 不稳定、流量耗尽、服务被限制 | 看控制台和 3x-ui 状态 |

## ✅ 这一章你需要得到什么

完成这一章后，你至少要做到：

- 客户端已经成功导入节点。
- 客户端显示连接成功。
- 查询到的出口 IP 是 VPS 所在地区。
- 目标服务可以正常访问。

如果测试失败，优先回到 3x-ui 节点配置、防火墙端口和客户端代理模式这三处检查。
