# 创建代理节点

安装好 3x-ui 后，下一步是在面板里创建一个可以被客户端导入的节点。

> ✅ 先看结论：节点就是客户端要连接的那组信息。创建节点时，最重要的是名称、端口、协议、域名和用户配置。

## 🧠 写给新手的理解

节点就是一组连接信息。客户端拿到这组信息后，就知道应该连接哪台服务器、哪个端口、使用什么协议。

你可以把节点理解成一张“通行证”。手机或电脑上的客户端导入这张通行证后，就能连接到你的 VPS。

## 🧾 创建节点前先确定

- 节点名称
- 使用的域名
- 使用的端口
- 协议类型
- 是否配置证书或 Reality
- 是否限制流量和到期时间

如果你还没确定协议细节，可以先不要急着创建。先把域名、端口、防火墙和 3x-ui 面板登录信息确认好。

## 🏷️ 节点命名建议

节点名字要让自己一眼看懂：

```text
美国-核云-01
美国-丽萨-01
新加坡-阿里云-备用
```

## 🧩 配置项解释

| 配置项 | 新手解释 | 示例 |
| --- | --- | --- |
| 备注 | 节点名字 | `美国-丽萨-01` |
| 端口 | 客户端连接入口 | `443` 或自定义端口 |
| 协议 | 节点类型 | VLESS、VMess、Trojan 等 |
| 域名 | 指向服务器的域名 | `us1.example.com` |
| 客户端 | 谁可以使用这个节点 | 自己、家人、朋友 |
| 流量限制 | 最多能用多少流量 | 100GB、500GB、不限制 |
| 到期时间 | 节点有效期 | 可选 |

## 🔐 协议怎么写

这部分建议等你确认最终方案后再定稿。对小白教程来说，不要一开始解释太多协议细节，可以先给一个推荐组合，再把其他方案放到附录。

可填写：

```text
我推荐新手先使用：待填写
原因：待填写
不推荐新手一开始使用：待填写
原因：待填写
```

## 📤 导出节点

创建完成后，通常可以复制：

- 单节点链接
- 二维码
- 订阅链接

新手建议优先用订阅链接，因为以后节点信息变化时，客户端刷新订阅即可。

## ✅ 这一章你需要得到什么

完成这一章后，你至少要得到：

- 一个已经创建成功的 3x-ui 节点。
- 一个可以导入客户端的订阅链接、二维码或单节点链接。
- 知道这个节点使用哪个域名和端口。
- 确认这个端口已经在防火墙或安全组里放行。

下一章会把这个节点导入电脑或手机客户端，并测试是否能正常连接。
